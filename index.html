    Methodology
    • Every number comes from data/observations.json (240 sourced rows). Nothing is invented in the UI.
    • The April 2026 live page (KPI cards, derived ROC / margin / PNL-per-head, and ~est annual filler) is captured in docs/legacy-site-capture.md. Those estimated/interpolated cells were not copied here. Prefer a blank cell over the old site’s filler.
    • Units: value / value_usd are millions unless unit=count (headcount).
    • Chart and table display USD millions. Hover a cell for the original line item (ANTI vs NTR vs turnover are not the same thing) and native currency.
    • When value_usd is missing, USD is converted with the documented yearly averages in docs/sources.md (EURUSD / GBPUSD). The tooltip says so.
    • Quarterly grain plots only period_type=quarter. Annual grain plots only period_type=annual. Annuals are never split into quarters.
    • Missing points are gaps: the line breaks. Conflicts (same firm + period + metric) keep every source; the cell shows the preferred confirmed value and lists the others.
    • Firm notes: docs/firms.md. Gaps: docs/gaps.md.
